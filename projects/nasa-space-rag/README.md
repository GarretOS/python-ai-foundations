# NASA Space RAG

NASA Space RAG is a beginner-friendly retrieval-augmented generation (RAG) application based on the TowardsAI lesson **Chat with Your Documents: A RAG Application**. It loads five NASA-derived text documents, creates Gemini embeddings, retrieves the two most similar documents for a question, and asks Gemini Flash to answer from those documents only.

## Learning objectives

- Use one Python class to organize a small application.
- Create and cache text embeddings with the Google GenAI SDK.
- Calculate cosine similarity manually with Python.
- Retrieve the most relevant documents for a question.
- Ground a Gemini-generated answer in retrieved source text.
- Connect a Python function to a Gradio Blocks interface.

## Setup

Use Python 3.10 or newer and install the two application dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r projects/nasa-space-rag/requirements.txt
```

Configure a Gemini API key in the shell. Do not put the key in this repository:

```bash
export GEMINI_API_KEY="your-key-here"
```

The application uses `gemini-embedding-2` for both document and question embeddings and `gemini-3.5-flash-lite` for answer generation. Confirm that these models are available to your Google AI Studio project and that your usage remains within the free tier before running live requests.

## Run the application

```bash
python3 projects/nasa-space-rag/nasa_space_rag.py
```

Open the local Gradio URL shown in the terminal.

## How RAG works here

1. The script loads the five `.txt` files as dictionaries containing `filename` and `content`.
2. Gemini creates one embedding per document. The embeddings are saved with the documents in `doc_embeddings.json`.
3. Later runs reuse that cache when it is readable and aligned.
4. Each question is embedded with the same embedding model.
5. Python calculates cosine similarity for every document, sorts the scores, and selects the top two.
6. Gemini Flash receives those two document contents and is instructed to answer only from them.

## Example questions

- What are the phases of the Moon?
- What is the International Space Station used for?
- What is a black hole?
- What are some facts about Mars?
- How is the Solar System organized?

## Displayed similarity scores

The second output shows the filenames of the two retrieved documents and the actual cosine similarity scores calculated by Python. Scores are rounded to three decimal places for display. They are retrieval measurements, not scores generated by Gemini, and a higher score means the question embedding is more aligned with that document embedding.

## Limitations

- The application uses whole documents and does not split them into chunks.
- Answers are limited to the five included NASA-derived text files.
- A cached embedding file must be regenerated if the source documents or embedding model changes.
- Gemini API access, quotas, model availability, and network connectivity are required for embeddings and answers.
- The free tier has rate and usage limits; this project does not enable billing.
- Similarity is a useful retrieval signal but does not guarantee that the retrieved documents contain a complete answer.
