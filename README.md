# python-ai-foundations

My structured learning repository for the Python for AI Engineering course by Louis-François Bouchard (Towards AI Academy).

This repository contains my course notes and the Python projects I build to apply the concepts I learn throughout the course.

## Structure

- `notes/` — lesson notes and summaries by section
- `projects/` — polished Python mini-projects built from course concepts

Each project is organized in its own directory and may include a Python script, Jupyter notebook, README, and requirements file.
